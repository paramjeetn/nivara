## 1. Executive Summary & Objective

### 1.1 Objective
The core tenet of Step 3 is **"Every number is traceable and defensible."**  
Prior to this step, business tariffs (commercial electricity and municipal water), carbon emission factors, BEE Energy Performance Index (EPI) thresholds, comfort constants, water leak multipliers, and anomaly thresholds were hard-coded as magic literals across multiple analytical engines and UI components.

Step 3 achieves complete decoupling and auditability by:
1. Creating a standardized, single-source-of-truth registry in `config/assumptions.yaml`.
2. Building a type-safe, validated Pydantic loader and in-memory registry engine in `src/campus_energy/assumptions.py` with `@lru_cache` and lookup APIs.
3. Systematically refactoring 8 core analytics and simulation modules plus the Streamlit operational dashboard and FastAPI web service to consume dynamic values through `assumptions.get_value(key)`.
4. Adding an interactive **Assumptions Registry audit table** to Dashboard Page 2 (Governance & Policy) and expandable `ℹ️ Assumptions used` panels to Forecasting, Alerts, and Executive Overview.
5. Implementing automated AST and grep unit tests (`tests/test_assumptions.py`) to guarantee zero hard-coded magic constants (`8.5`, `0.82`) remain in core calculation pipelines.

## 3. Assumptions Registry Architecture

### 3.1 Pydantic Data Contracts
In `src/campus_energy/assumptions.py`, each assumption entry adheres strictly to:

```python
ConfidenceLevel = Literal["high", "medium", "low", "needs_verification"]

class Assumption(BaseModel):
    key: str = Field(description="Dot-delimited identifier (e.g. 'tariff.electricity_commercial')")
    value: Any = Field(description="Typed or numeric constant value")
    unit: str = Field(description="Engineering or financial unit")
    description: str = Field(description="Human-readable explanation")
    source: str = Field(description="Documented authority, standard, code, or published order")
    source_date: str = Field(description="Publication or effective date (YYYY-MM-DD)")
    confidence: ConfidenceLevel = Field(description="Data confidence rating")
    applies_to: list[str] = Field(default_factory=lambda: ["all"])
    notes: str | None = Field(default=None)
```

### 3.2 Registry Loader & Lookup API
The `AssumptionsRegistry` provides clean, high-performance lookup capabilities:
- `load_assumptions(path="config/assumptions.yaml")`: Uses `@lru_cache(maxsize=16)` and resolves paths across repository roots and alternative folder structures (`config` vs `configs`).
- `get(key: str) -> Assumption`: Returns the full model; raises a descriptive `KeyError` if missing.
- `get_value(key: str, default=_SENTINEL) -> Any`: Returns the typed value directly; supports fallback defaults and raises `KeyError` if no default is provided for an unregistered key.
- `list_by_prefix(prefix: str) -> list[Assumption]`: Enables domain grouping (e.g., `bee.epi.`, `tariff.`, `anomaly.`).
- Module-level singleton accessors: `assumptions.get(key)` and `assumptions.get_value(key)`.
